# Mohamed Rabie Ghediri — Portfolio

Personal portfolio for a final-year Data Engineering and Decision Systems engineering student interested in data engineering, machine learning, NLP, and generative AI.

## Features

- English/French language switcher
- Light, dark, and system themes
- Responsive editorial-style design
- Experience and education timelines
- Technologies and projects sections
- Dedicated project detail pages
- Data Engineering and AI CVs
- GitHub, LinkedIn, and email links

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · React Router · Framer Motion · Lenis · Vercel

## Routes

- `/` — Homepage
- `/projects` — All projects
- `/projects/:slug` — Project details
- `/contact` — Contact page

## Development

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```
